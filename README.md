# IndFloorSeg: A Pixel-Level Annotated Synthetic Dataset for Industrial Floor Contamination Segmentation

**IndFloorSeg** is a synthetic RGB image dataset with pixel-level semantic annotations for vision-based industrial floor contamination detection. It is intended to support research on semantic segmentation, contamination-aware visual perception, and autonomous floor-cleaning systems.

The dataset accompanies the manuscript **“Benchmarking Semantic Segmentation Networks for Vision-Based Industrial Floor Contamination Detection.”** The study benchmarks six encoder–decoder segmentation configurations and investigates segmentation quality, contaminated-floor detection, training-data availability, and inference time.
